# 🎓 Learning with O

### Learn. Build. Break. Fix. Repeat. 🚀

Welcome to the official source-code repository for **Learning with O** — a YouTube channel focused on practical learning in **Data, Analytics, AI, and Microsoft technologies**.

This repository contains the **source code, datasets, SQL scripts, Power BI files, Fabric examples, and other resources** used throughout the channel.

---

## 📺 Follow the Journey

> **Learning with O** is all about learning by actually building things.

Whether you're learning **SQL, Power BI, Microsoft Fabric, Azure, Data Engineering, or AI**, you'll find practical examples here that you can download, experiment with, and build upon.

**🎯 The goal:** Turn concepts into something you can actually use.

## 🚀 How to Use This Repository

### 1️⃣ Clone the repository

```bash
git clone <repository-url>
```

### 2️⃣ Navigate to the tutorial

Find the folder corresponding to the YouTube video you're following.

### 3️⃣ Download the required dataset

Datasets used by the tutorial are available in the relevant `Data` folder.

### 4️⃣ Follow along

Open the source files and build the solution alongside the video.

### 5️⃣ Experiment

Don't just copy the code.

**Change it. Break it. Fix it. Make it yours.**

That's where the real learning happens. 💡
